## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Saras2909/Mini-Projects.git
cd Mini-Projects
```

### 2. Set Up Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Navigate & Run Projects
Each project operates independently with its own documentation and environment setup. Navigate to any project folder to get started:

```bash
cd Boston
# Refer to project README for dependencies and setup
```

Refer to each project's individual `readme.md` for specific execution steps and usage guides.
